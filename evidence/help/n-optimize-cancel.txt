Cancel a running optimization or evaluation job by its operation ID.

Only jobs in a non-terminal state (pending, running) can be cancelled.

Usage:
  agent optimize cancel <operation-id> [flags]

Examples:
  # Cancel a running job
  azd ai agent optimize cancel opt_abc123

Flags:
      --endpoint string           Optimization service endpoint (for local dev)
  -h, --help                      help for cancel
  -p, --project-endpoint string   Foundry project endpoint URL

Global Flags:
  -C, --cwd string           Sets the current working directory
      --debug                Enables debug and diagnostics logging
  -e, --environment string   The name of the environment to use
      --no-prompt            Runs without prompts. Uses existing values; fails if any required value or decision cannot be resolved automatically.
  -o, --output string        The output format (default "default")
