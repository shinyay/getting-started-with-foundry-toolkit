Show an eval definition, run history, or run details.

If eval-id is omitted, the most recent eval from the current environment is used.

Usage:
  agent eval show [eval-id] [flags]

Flags:
      --eval-run-id string   Show details for a specific eval run
  -h, --help                 help for show
      --limit int            Maximum number of runs to show (default 20)
  -O, --out-file string      Export full run results to a JSON file

Global Flags:
  -C, --cwd string           Sets the current working directory
      --debug                Enables debug and diagnostics logging
  -e, --environment string   The name of the environment to use
      --no-prompt            Runs without prompts. Uses existing values; fails if any required value or decision cannot be resolved automatically.
  -o, --output string        The output format (default "default")
